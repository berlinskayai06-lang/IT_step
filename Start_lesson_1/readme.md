# Library Management System

## Description

Library Management System is a Python project designed to manage a collection of books. The project provides a foundation for storing book information, organizing library data, and testing application functionality.

## Project Structure

```text
module_git/
├── src/
│   ├── main.py
│   └── library.py
├── tests/
│   └── test_pre_commit.py
├── books/
│   └── books.json
├── config/
│   └── settings.json
├── main.py
└── README.md
```

## Technologies

- Python
- Git
- JSON
- PyCharm

## Project Goals

- Develop a simple library management application.
- Store information about books in JSON format.
- Organize Python code into modules.
- Practice Git version control.
- Learn automated testing.
